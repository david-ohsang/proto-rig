# proto-rig — 스택 디펜스 코어 메커니즘 검증 리그

신규 프로젝트의 코어 메커니즘이 재미있는지만 확인하기 위한 **그레이박스 프로토타입**입니다.
게임 빌드가 아니라 **검증 도구**입니다. 내부 플레이테스트 용도로만 씁니다.

**▶ 플레이 : https://david-ohsang.github.io/proto-rig/**

폰 브라우저에서 링크만 열면 됩니다. 설치·계정·다운로드 없음.

---

## 이게 답하려는 질문 딱 하나

> 유닛을 쌓고 · 전투 중에 카드를 고르고 · 터치로 집중 사격하는 이 루프가,
> **아트와 성장 시스템이 하나도 없는 상태에서도 재미있는가?**

아트·메타 성장·수집·상점·과금·튜토리얼은 **일부러 전부 없습니다.**
여기서 재미가 안 나오면 아트를 붙여도 안 납니다.

## 무엇을 측정하는가

플레이하면 아래 4개가 자동으로 기록되고, 3판이 끝나면 결과 시트에 한 화면으로 나옵니다.

| 가설 | 리그가 뽑는 값 |
|---|---|
| **H1** 논스톱 카드가 쾌감인가 스트레스인가 | 카드 선택 소요 ms · **선택 중 잃은 체력** · 선택 시점의 모드 |
| **H2** 매 판 다른 빌드가 나오는가 | 판별 획득 순서(빌드) · 최종 스택 · 3판이 서로 다른 수 |
| **H3** 집중 사격이 할 일을 주는가 | 사용 횟수·초 · **집중 없이 넘긴 웨이브 수** |
| **H4** "아슬아슬했다"가 나오는가 | 판별 최저 체력 % |

결과 화면 하단의 JSON을 복사해 진행자에게 전달하면 됩니다.

## 게임 구조

- **세로 화면 · 사이드뷰(벨트스크롤)** — 유닛 스택이 왼쪽에 서서 오른쪽으로 사격하고,
  적은 오른쪽에서 왼쪽으로 밀고 들어옵니다.
- **유닛 4종** 미니건 · 미사일 · 레이저 · 수류탄, 최대 6칸 스택
- **인접 시너지 7종** — 위아래로 붙은 두 유닛 조합에 따라 발동.
  **획득 순서가 곧 빌드**입니다.
- **카드 12장** 합류 4 / 강화 6 / 시너지 2. 레벨업마다 3장 중 1장.
- **카드 모드 3종** 논스톱 · 슬로우 · 정지 — H1의 A/B 대조군입니다.
  화면 아래 버튼으로 즉시 전환.
- 5웨이브마다 보스.

## 조작

- 세로로 잡으세요.
- **화면을 꾹 누른 채 끌면 집중 사격** (누르는 동안 게이지가 닳습니다)
- 카드는 하단 패널을 탭

## 테스터에게 안내할 때

> 폰으로 링크를 열고, **설명 없이 3판을 이어서** 플레이해 주세요.
> 3판이 끝나면 결과 화면의 텍스트를 복사해서 보내 주세요.

설명을 하면 "5분 안에 이해되는가"를 같이 검증할 수 없습니다.
진행자는 플레이 직후 구두로 5문항을 묻되, **"재밌었어요?"는 묻지 않습니다.**
마지막 문항은 **"한 판 더 하고 싶으신가요? (Y/N)"** 로만 받습니다.

## 튜닝

화면 아래 `튜닝` 버튼을 누르면 슬라이더 5종이 나옵니다 —
스폰 속도 · 적 체력 · 레벨업 필요량 · 슬로우 강도 · 집중 배율.
**플레이 중에 실시간으로 반영**되므로 테스트 자리에서 바로 값을 찾을 수 있습니다.
지금 값은 초기값일 뿐 밸런스가 잡힌 상태가 아닙니다.

## 기술 메모

- `index.html` **단일 파일**. 빌드 과정 없음, 외부 의존 없음(구글 폰트만).
- Canvas 2D + 바닐라 JS. 논리 해상도 540×960 고정, 화면 크기에 맞춰 스케일.
- GitHub Pages 자동 배포 — `main` 에 푸시하면 1분 안에 반영됩니다.
- 페이지에 `noindex,nofollow` 를 걸어 검색 엔진 색인을 막아 두었습니다.

## 상태

- ✅ 코어 루프 · 지표 측정 · 3판 결과 시트 · 모바일 동작(60fps)
- ⏳ 밸런스 미완 (플레이테스트 중 튜닝 예정)
- ❌ 아트 · 사운드 · 메타 성장 · 과금 — 이 단계에서는 만들지 않습니다
